## How the live page updates automatically

1. Claude edits `website/project-12.html` in the local folder as part of every project update.
2. You commit and push this repo (GitHub Desktop: Commit -> Push origin).
3. The workflow `.github/workflows/sync-website.yml` copies the page into the website repo
   `hamidf2024/hamidf2024.github.io` (`stocks-investment/project-12.html`) and pushes it.
4. GitHub Pages republishes the site, usually within a minute or two.

### One-time setup (needed before step 3 works)
1. GitHub -> your avatar -> **Settings -> Developer settings -> Personal access tokens -> Fine-grained tokens ->
   Generate new token**. Repository access: **Only select repositories -> hamidf2024.github.io**.
   Permissions: **Contents: Read and write**. Generate and copy the token.
2. Open https://github.com/hamidf2024/p12-best-stocks-investment/settings/secrets/actions ->
   **New repository secret**. Name: `SITE_TOKEN`. Value: the token. Save.
3. Test: **Actions** tab -> "Publish Project 12 page" -> **Run workflow**.

Preview locally: the page needs the site's `style.css` one folder up; view it on the live site after publishing.
